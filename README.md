# Штурман маршрута (статический сайт)

Минимальное веб-приложение для поездки в условиях плохой навигации.

- Без backend
- Без React
- Без сборки
- Без внешних API

Приложение работает как ручной список контрольных точек маршрута:

- отмечает текущий этап,
- позволяет двигаться вперёд/назад,
- показывает прогресс в формате «Этап X из Y»,
- выводит «Вы прибыли» на финальном этапе,
- позволяет зафиксировать ручную привязку, если «потерялись»,
- позволяет редактировать этапы на месте и быстро добавлять новые этапы,
- сохраняет всё в `localStorage`.

## Файлы

- `index.html` — структура страницы.
- `style.css` — минималистичный адаптивный стиль (в т.ч. для iPhone Safari).
- `app.js` — логика приложения и хранение данных.

## Локальный запуск

Откройте `index.html` в браузере.

## Публикация на GitHub Pages

### Вариант 1: через ветку `main` (root)

1. Создайте репозиторий на GitHub.
2. Загрузите в корень репозитория файлы:
   - `index.html`
   - `style.css`
   - `app.js`
   - `README.md`
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`
   - **Folder**: `/ (root)`
5. Нажмите **Save**.
6. Подождите 1–3 минуты, после чего появится URL сайта вида:
   `https://<username>.github.io/<repo-name>/`.

### Вариант 2: через папку `/docs`

Если хотите хранить сайт в `/docs`, переместите туда `index.html`, `style.css`, `app.js`,
а в **Settings → Pages** выберите:

- **Branch**: `main`
- **Folder**: `/docs`

## Примечания

- Сохранение маршрута работает через `localStorage` текущего браузера.
- Данные не синхронизируются между устройствами автоматически.
